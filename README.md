## About the book

This textbook covers rigorous quantitative analysis when sample sizes are small. Topics include study design, measurement quality, exact and resampling tests, nonparametric inference, penalised and Bayesian regression, missing data, uncertainty reporting, and five worked projects in R.

Chapters are structured for independent reading. Each chapter includes worked R examples with rendered output, interactive code cells (web edition), and self-assessment quizzes.
